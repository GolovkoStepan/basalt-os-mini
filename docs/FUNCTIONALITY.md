# BASALT-OS-MINI — что система умеет

Функциональные требования и границы для Cardputer. Документ отвечает на вопрос
«что это за машина», а не «в каком порядке это писать» (порядок — в
[`ROADMAP.md`](ROADMAP.md)).

| | |
|---|---|
| **Создан** | 20.10.2026 |
| **Плата** | M5Stack Cardputer (K132), ESP32-S3FN8, 512 КБ SRAM, без PSRAM |
| **Решения** | родная ФС — **FAT32**; терминал — **ANSI-подмножество** |

Это **источник истины по терминальной части** для обоих проектов.
`basalt-os` (Tab5) наследует разделы 2–5, 7–12 и описывает только отличия.

Приоритеты: **P0** — без этого это не система (MVP), **P1** — пригодно для
ежедневного использования, **P2** — расширения.

---

## 1. Экран и текстовый режим

Аппаратно: ST7789V2, 240×135, SPI.

| Параметр | Значение | Как получено |
|---|---|---|
| Ячейка символа | **6×9** (глиф 5×7 + 1 px справа + 2 px снизу) | 240/6 = 40, 135/9 = 15 ровно |
| Сетка | **40 колонок × 15 строк** | |
| Символов на экране | 600 | |
| Текстовая матрица | 600 × (1 Б символ + 1 Б атрибут) = **1.2 КБ** | |
| Полоса рендера строки | 240 × 9 × 2 Б = **4.3 КБ** | по DMA, одна строка |
| Полный кадр | 240 × 135 × 2 Б = 64.8 КБ, **~13 мс** при 40 МГц SPI | 64800 × 8 / 40e6 |
| Одна строка | **0.87 мс** | 4320 × 8 / 40e6 |
| Scrollback | 500 строк × 40 × 2 Б = **40 КБ** | настраивается |

- **P0** Текстовый режим 40×15, шрифт 5×7 (ASCII 0x20…0x7E).
- **P0** Курсор: позиция, мигание по таймеру, видимость.
- **P0** Перерисовка только изменённых строк (dirty lines), не всего экрана.
- **P0** Прокрутка вверх на строку без перерисовки всего экрана: сдвиг
  матрицы либо аппаратная прокрутка ST7789 (`VSCRDEF`/`VSCSAD`) — выбрать
  по замеру.
- **P1** Кириллица: +66 глифов (+462 Б), вход в **UTF-8**, внутри — code point.
- **P1** Инверсия, подчёркивание, «жирный» как атрибуты (жирный — двойной
  вывод глифа со сдвигом, без второго шрифта).
- **P2** Крупный режим 30×11 при ячейке 8×12, по команде.

Шрифт — **свой**, генерируемый скриптом (по образцу `pulsar/tools/make_font.py`).

## 2. TTY и ANSI

Реализуется как настоящий tty-слой, а не как `printf` в экран.

### 2.1 Line discipline

- **P0** Канонический режим: построчная буферизация, эхо, `Backspace`,
  `Enter` (`\n` → `\r\n` при выводе).
- **P0** Raw-режим: без эха и построчной обработки — нужен программам,
  которые сами управляют экраном.
- **P1** Управляющие символы: `Ctrl-C` (прерывание), `Ctrl-D` (EOF),
  `Ctrl-Z` (приостановка), `Ctrl-S`/`Ctrl-Q` (flow control).
- **P1** Размер окна (`rows`, `cols`) как свойство tty.
- **P2** Несколько tty: экран и USB-консоль одновременно, переключение
  по `Ctrl-]`.

### 2.2 ANSI-последовательности

Формат: `CSI` = `ESC [` (0x1B 0x5B), `OSC` = `ESC ]`.

**Курсор и стирание**

| Последовательность | Действие | Приоритет |
|---|---|---|
| `CSI n A` / `B` / `C` / `D` | курсор вверх/вниз/вправо/влево | P0 |
| `CSI r;c H` / `CSI r;c f` | позиция (1-based) | P0 |
| `CSI n G` | колонка | P1 |
| `CSI n d` | строка | P1 |
| `CSI H` | домой | P0 |
| `CSI n J` | стереть экран (0 — до конца, 1 — до начала, 2 — весь) | P0 |
| `CSI n K` | стереть строку (0/1/2) | P0 |
| `CSI n P` / `@` | удалить / вставить символы | P1 |
| `CSI n L` / `M` | вставить / удалить строки | P1 |
| `CSI s` / `CSI u` | сохранить / восстановить позицию | P1 |
| `ESC 7` / `ESC 8` | то же (DECSC/DECRC) | P1 |

**Атрибуты (SGR, `CSI … m`)**

| Что | Коды | Приоритет |
|---|---|---|
| Сброс | `0` | P0 |
| Инверсия | `7`, выкл `27` | P0 |
| Подчёркивание | `4`, выкл `24` | P1 |
| Жирный | `1`, выкл `22` | P1 |
| Мигание (инверсия по таймеру) | `5`, выкл `25` | P2 |
| Цвет текста | `30…37`, `90…97` | P1 |
| Цвет фона | `40…47`, `100…107` | P1 |
| 256 цветов | `38;5;n` / `48;5;n` | P2 (палитра 16 оттенков) |

Палитра — 16 значений RGB565, подобранных под читаемость на IPS-панели,
а не стандартные VGA.

**Режимы и экраны**

| Последовательность | Действие | Приоритет |
|---|---|---|
| `CSI ? 25 h` / `l` | показать / скрыть курсор (DECTCEM) | P0 |
| `CSI ? 1049 h` / `l` | альтернативный экран (для редактора) | P1 |
| `CSI ? 7 h` / `l` | автоперенос (DECAWM) | P1 |
| `CSI r; r` | scroll region (DECSTBM) | P1 |
| `CSI 6 n` | отчёт о позиции курсора (DSR) | P1 |
| `CSI c` | идентификация терминала (DA) | P2 |
| `OSC 0 ; title BEL` | заголовок (в статус-строку или игнор) | P2 |

**Сознательно не поддерживаем:** мышь (нет указателя), `OSC 52` (некуда),
DCS/шестьэл, графику (Sixel/Kitty).

**P0-критерий:** собственный `less`-подобный просмотрщик корректно
прокручивает, стирает и позиционирует курсор; вывод с цветами выглядит
правильно.

## 3. Клавиатура

Аппаратно (K132): матрица через 74HC138 — адрес G8/G9/G11, чтение
G13/G15/G3/G4/G5/G6/G7, нажатие = LOW.

- **P0** Скан 8 строк × 7 бит → 56 клавиш, интервал 10 мс.
- **P0** Антидребезг (N подтверждений), удержание, автоповтор
  (задержка ~400 мс, период ~50 мс).
- **P0** Раскладка US QWERTY, `Shift`/`Ctrl`/`Fn`.
- **P0** Слой `Fn` — обязателен, иначе нет стрелок и `Esc`:

| Сочетание | Даёт | Статус |
|---|---|---|
| `Fn` + `` ` `` | `Esc` | по документации espp, **сверить на плате** |
| `Fn` + `1`…`0`, `-`, `=` | `F1`…`F12` | по документации espp, сверить |
| `Fn` + `Backspace` | `Delete` | по документации espp, сверить |
| `Fn` + `;` / `.` / `,` / `/` | ↑ / ↓ / ← / → | по документации espp, сверить |

- **P1** `Tab`, `Caps Lock` (если есть), русская раскладка по своей комбинации.
- **P1** События, а не символы: драйвер отдаёт (код, модификаторы,
  нажатие/отпускание), раскладка — отдельный слой.
- **P2** Системные комбинации: переключение tty, перезагрузка, дамп экрана
  в файл.

**P0-критерий:** все 56 клавиш читаются, без «залипаний» и потерь при быстром
наборе; `Fn` работает; строка в шелле набирается без искажений.

## 4. Файловая система

| Точка | Что | Тип |
|---|---|---|
| `/` | **FAT32** на microSD — читается на маке | блочное устройство + FAT32 |
| `/tmp` | ramdisk в свободной SRAM | линейный буфер |
| `/dev` | устройства (таблица, не ФС) | — |

**Чтение (P0):** MBR → раздел → VBR (`BPB_BytsPerSec`, `BPB_SecPerClus`,
`BPB_RsvdSecCnt`, `BPB_NumFATs`, `BPB_FATSz32`, `BPB_RootClus`); кластерные
цепочки; записи каталога 32 Б; атрибуты (`0x10` каталог, `0x20` архив,
`0x0F` — длинное имя); FSInfo.

**Запись (P0):** создание файла и каталога, выделение и освобождение цепочки,
обновление размера в записи каталога, FSInfo.

**LFN (P1):** цепочка записей `0x0F`, UTF-16LE по 13 символов, контрольная
сумма от 8.3-имени. До этого — 8.3 с автогенерацией (`FILE~1.TXT`).

**Устойчивость (P1):** порядок записи данные → FAT → каталог; кэш на запись
со сбросом по таймеру и по `sync`.

Принятые ограничения: файл ≤ 4 ГБ − 1, кластер 512 Б…32 КБ, нет
журналирования.

**VFS:**

- **P0** `open/read/write/close/seek`, `stat`, `readdir`, `unlink`, `mkdir`,
  `rename`; таблица открытых файлов; проверки прав нет (нет пользователей).
- **P1** Символьные устройства через тот же интерфейс: `/dev/tty`, `/dev/sd0`,
  `/dev/audio`, `/dev/ir`, `/dev/battery`.
- **P1** Перенаправление в шелле: `>`, `>>`, `<`, `|`.

**P0-критерий:** карта из FAT32, отформатированная на маке, монтируется;
`ls`/`cat` работают; созданный файл открывается на маке; выдёргивание карты
без `sync` не роняет систему.

## 5. Шелл и команды

**P0:**

| Команда | Что делает |
|---|---|
| `ls` | список, с `-l`, размеры и даты |
| `cd`, `pwd` | навигация |
| `cat` | вывод файла |
| `cp`, `mv`, `rm`, `mkdir` | файловые операции |
| `echo` | с перенаправлением |
| `date` | время, установка |
| `free`, `df` | память и место |
| `top` | задачи, состояние, остаток стека |
| `help` | список команд |
| `reboot` | перезагрузка |
| `beep` | звук |

**P1:** `less`, `edit`, `hexdump`, `find`, `grep` (простой), `history`, `env`,
`peek`/`poke`, `time`, `sleep`, `wget`, `ntpdate`, `ir`, `play`, `rec`,
`ruby`.

Особенности:

- **P0** История (`↑`/`↓`), редактор строки с движением курсора,
  `Ctrl-A/E/K/U/W`.
- **P0** Кавычки, пробелы, `#` — комментарий.
- **P1** `Tab`-дополнение по файлам и командам.
- **P1** `;`, `&&`, конвейеры `|`; скрипты (`source script.sh`).
- **P2** Переменные окружения, `$?`, подстановка `*`.

**P0-критерий:** не вынимая карту — создать файл, отредактировать, сохранить,
скопировать, удалить, посмотреть список с датами.

## 6. Время

RTC на плате нет.

- **P0** Монотонное время (тики), `uptime`, задержки, таймеры.
- **P1** NTP при наличии Wi-Fi; хранение времени последней синхронизации
  на SD, чтобы после перезагрузки дата была хотя бы приблизительной.
- **P2** Внешний RTC через Grove (DS3231 и подобные).

**P1** Временные метки файлов читаются и пишутся по-настоящему — иначе
`ls -l` бессмыслен.

**P1** Будильник и таймер со звуком.

---

## 7. Сеть

Wi-Fi в самом SoC, сопроцессора нет. Драйвер — бинарный блоб, которому нужны
примитивы ОС (семафоры, очереди, задачи, heap).

- **P1** Шим FreeRTOS-примитивов на своём планировщике + lwIP. Отдельная
  большая веха с допущенным откатом (см. роадмап).
- **P1** `wifi scan`, `wifi connect ssid pass`, `ip`, `wget`, `ntpdate`,
  `ping` (свой ICMP).
- **P2** `telnet` (клиент, BBS и удалённые машины), MQTT-минимум, `httpd`
  (отдать файл с SD).
- **P2** Приём файла по сети и обновление своей прошивки своим протоколом.

**Критерий P1:** время получено по NTP, файл скачан по HTTP в `/` на SD.

---

## 8. Звук

Аппаратно: NS4168 (I2S), микрофон SPM1423 (PDM). **G43 делится между LRCLK
динамика и PDM-клоком микрофона** — одновременно нельзя.

- **P0** `beep`; `\a` (bell) в tty.
- **P1** WAV с SD: 16-бит PCM, моно, 8/16/22.05/44.1 кГц, стриминг по DMA
  без загрузки файла в память.
- **P1** Запись: диктофон в WAV, индикатор уровня псевдографикой.
- **P2** Простой синтез: огибающие, две-три ноты.

**Критерий P1:** WAV играет целиком без заиканий; запись воспроизводится
на маке.

---

## 9. ИК-передатчик

Только TX (G44), приёмника нет — обучения пультов не будет.

- **P1** NEC и Sony SIRC через RMT или точный таймер.
- **P1** `ir send nec 0x20DF 0x10EF`, таблица кодов на SD, макросы в скриптах.
- **P2** RC5 и «сырой» список импульсов в микросекундах.

---

## 10. USB

Native OTG плюс USB Serial/JTAG.

- **P0** Консоль по USB Serial/JTAG (он же путь прошивки и GDB).
- **P1** Режим устройства: CDC (консоль) и **MSC** (карта видна на маке как
  флешка).
- **P2** Режим хоста: USB-клавиатура, USB-флешка как второй диск.
- **P2** XMODEM/ZMODEM приём по консоли — закинуть файл без Wi-Fi и без
  вынимания карты.

---

## 11. Ruby

- **P1** **mruby/c** (не полный mruby) — бюджет без PSRAM; проверить
  фактическим размером бинарника и heap.
- **P1** Доступ: ФС, время, звук, ИК, сеть, батарея, tty.
- **P1** `ruby script.rb`, аргументы, код возврата.
- **P2** Своя «стандартная библиотека» на Ruby: `ls`, `cat`, `edit` поверх
  системных вызовов — доказательство полноценности языка.
- **P2** Ошибка печатает место и стек, но не роняет систему.

**Критерий P1:** скрипт с SD читает файл, обрабатывает строки, пишет результат
и играет звук.

---

## 12. Диагностика

- **P1** `top`: задачи, состояния, остаток стека (на S3 стеки небольшие),
  время CPU.
- **P1** Паника при исключении: регистры, стек вызовов по адресам, текущая
  задача — а не тишина.
- **P1** Логирование сессии в файл на SD.
- **P2** Дамп экрана в текст, `peek`/`poke`, счётчики прерываний.

## 13. Бюджет памяти (512 КБ SRAM, без PSRAM)

| Потребитель | Оценка |
|---|---|
| Ядро, планировщик, syscalls | 25 КБ |
| Текстовая матрица + курсор | 1.5 КБ |
| Полоса рендера строки | 4.3 КБ |
| Шрифт (ASCII + кириллица) | 1.2 КБ |
| Scrollback 500 строк | 40 КБ |
| Кэш блоков SD (32 × 512 Б) | 16 КБ |
| VFS + FAT32 | 10 КБ |
| TTY + ANSI + шелл | 15 КБ |
| Стеки задач (6 × 4 КБ) | 24 КБ |
| **Основа итого** | **~140 КБ** |
| Wi-Fi + lwIP | 60–100 КБ |
| mruby/c | 40–70 КБ |
| Звук (буферы DMA) | 8 КБ |
| **С сетью и Ruby** | **~250–320 КБ** |

Всё помещается, но **без запаса на роскошь**: крупные буферы, полный mruby
и «красивые» структуры данных на 512 КБ не пройдут. Это ограничение делает
проект честным — каждая килобайтная трата должна быть оправдана.

## 14. Вне области — сознательно

| Не делаем | Почему |
|---|---|
| Графический UI, окна, мышь | 240×135, нет указателя. Окна — в `basalt-os` |
| Изоляция задач, виртуальная память | На S3 нет MMU |
| Пользователи и права | Нет способа их изолировать |
| Браузер, изображения, видео | Нет ни памяти, ни пикселей |
| Полный mruby / CRuby | 512 КБ без PSRAM |
| Обучение ИК-пультов | Нет приёмника |
| Запись и воспроизведение звука одновременно | G43 физически общий |
| POSIX/ELF-совместимость | Свои syscalls; переносимость через ANSI, не через POSIX |

## 15. Открытые вопросы

1. **Скорость SPI экрана** — 40 МГц даёт 13 мс на кадр; проверить 60/80 МГц
   на артефакты. От этого зависит, нужна ли частичная перерисовка вообще.
2. **Аппаратная прокрутка ST7789** (`VSCRDEF`/`VSCSAD`) — если работает без
   разрывов, прокрутка станет почти бесплатной.
3. **Скорость SD** — измерить чтение и запись; от этого зависит смысл кэша
   на 32 блока и WAV-стриминга.
4. **Карта `Fn`** — по документации espp, требует проверки на нашей плате.
5. **Реалистичность Wi-Fi без IDF** — оценить объём шима после стабилизации
   ядра.
6. **mruby/c против полного mruby** — решить по факту размера после сборки.
